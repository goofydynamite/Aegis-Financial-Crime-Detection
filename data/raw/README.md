# Raw data

This folder is git-ignored. Download the IBM AML dataset (Altman et al., NeurIPS 2023):

https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

Place these three files here (pick a dataset prefix and set `data.dataset` in `config.yaml`):

- `LI-Small_Trans.csv`
- `LI-Small_Patterns.txt`
- `LI-Small_accounts.csv`

The full Kaggle archive is ~8 GB zipped and ~42 GB unzipped. Download individual files
from the Data Explorer, or extract only the ones you need.
